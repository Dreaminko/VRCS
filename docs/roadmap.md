# 路线图

当前 0.1 版本已打通系统音频、VAD、本地与云端语音识别、字幕存储、翻译与实时推送链路，桌面端与 Windows x64 发布安装包可用。以下功能尚未实现，按优先级排列。

## 计划中

- **VR Overlay**：在 VR 头显内直接显示字幕，无需切出 VRChat 查看桌面窗口
- **说话人分离**：区分对话中的不同说话人并在字幕中标注
- **翻译增强**：术语表、按会话切换目标语言、译文质量反馈与批量重译
- **完整词典导入**：Yomitan 格式词典包的批量导入、词频与变体处理已经具备基础，后续完善大词库的导入体验与查询性能

## 候选方向

- 更多识别引擎与模型后端
- 字幕样式自定义（字体、颜色、位置）
- 对话导出与 Anki 批量回顾
- macOS / Linux 支持（Core 已具备跨平台结构，采集层需要对应实现）
