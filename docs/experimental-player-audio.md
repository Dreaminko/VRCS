# VRChat 分玩家独立音轨（实验性）

分玩家独立音轨为每位 VRChat 玩家建立独立的语音输入，分别进行识别和翻译。多人同时讲话时，聊天页面、桌面字幕、VR 视野字幕和手腕对话可以显示各自的姓名、原文与译文。

该功能默认关闭。启用后，各音轨使用当前配置的识别服务、翻译服务和语言设置，支持本地识别、云端识别及服务提供的流式同传。可用的翻译目标数量和并发能力取决于所选服务。

## 使用条件

- **Windows 与管理员权限**：桌面端可以通过 UAC 请求提权，并在重新打开后继续操作。授权时使用同一 Windows 账户。使用远程 Core 时，运行 Core 的 Windows 进程需要管理员权限。
- **关闭 Windows 内存压缩并重启电脑**：可以在音频设置中的「Windows 内存压缩 → 检查与管理」完成检测、关闭和恢复。
- **NTFS 分页文件**：分页文件需位于 NTFS 卷根目录的 `pagefile.sys`。在分玩家音轨设置中选择对应盘符，默认 `C:`。
- **VRChat 安装与日志**：保持标准 `output_log_*.txt` 日志开启并可读。程序自动从运行中的 VRChat 安装目录加载 `VRChat_Data/Plugins/x86_64/opus.dll`，也可在设置中指定该库的本地绝对路径。
- **IPv4 网络**：采集支持 VRChat 进程与服务器 `27002` 端口之间的 IPv4 UDP 流量。网卡、VPN、加速器和系统网络栈会影响原始套接字的接收能力。

## 开始使用

1. 在设置中选择识别、翻译服务和目标语言。
2. 打开「设置 → 音频来源 → 其他人的声音」，选择「VRChat 分玩家独立音轨（实验性）」，确认分页文件盘符。
3. 点击开始转写，阅读实现说明与免责声明，等待至少 3 秒后确认。需要管理员权限时，程序会请求 UAC 授权；内存压缩状态不符合要求时，会打开管理弹窗。
4. 登录 VRChat 并进入世界。程序会在世界加载完成后自动尝试解析和认证密钥，收到玩家语音后开始识别与翻译。等待过程中可以随时停止。

**要匹配玩家姓名，请先开启采集再进入世界，或重新加载当前世界。** 已在世界内开启采集时，程序可能收到语音，但缺少此前发送的玩家身份信息；身份尚未匹配的字幕会显示「音轨 N」，收到姓名后会补全该音轨的记录与预览。

获取密钥时，会请求 Windows 将部分游戏内存页换出到磁盘分页文件，再从中尝试解析密钥，期间可能使游戏短暂停顿。

## 内存压缩管理

「检查与管理」会显示当前状态，并提供关闭或恢复内存压缩的操作。每次修改前都会说明影响并要求确认；权限不足时使用同一套 UAC 提权流程。修改会暂停当前转写，完成后需要保存工作并重启 Windows。

关闭内存压缩可能增加物理内存占用，内存紧张时也可能增加磁盘分页活动。退出 VRCS 不会恢复系统设置；需要恢复时，在同一入口选择开启并按提示重启电脑。恢复开启后，分玩家音轨功能需要再次关闭内存压缩才能使用。

启动采集前会检查管理员权限、内存压缩状态和待重启标记。仅重新打开 VRCS 不会清除系统重启提醒。

## 选择玩家与过滤显示

聊天页面的「人员与译文显示」提供三类控制：

在 VR 中，也可点击手腕快捷菜单的人员图标打开同名设置。设置在快捷按钮上方展开，与快捷菜单一起固定在手腕上；关闭设置不会撤销已生效的修改。人员与原文语言分别分页显示，修改与桌面使用同一份设置。即使未启用分玩家音轨，仍可调整已有记录和原文语言的显示；玩家处理选择仅在分玩家模式且 Core 可用时启用。

| 设置 | 作用 | 适用范围 |
| --- | --- | --- |
| 处理哪些玩家 | 默认翻译所有人，也可只翻译选定玩家 | 音频解码、识别和翻译 |
| 隐藏某人的记录 | 隐藏该音轨的字幕，可随时恢复 | 聊天、桌面字幕、VR 字幕、手腕对话 |
| 隐藏的原文语言（可多选） | 隐藏符合所选原文语言的整条发言，包括原文及其全部译文 | 聊天、桌面字幕、VR 字幕、手腕对话 |

玩家选择按 **VRChat 用户 ID** 保存到本地，切世界和重启 VRCS 后可以复用。再次遇到已保存的用户时，程序会更新其昵称。选择可以在采集中修改；未选中的玩家不会进入语音解码、识别或翻译，身份尚未确认的音轨也不会进入「仅翻译选定的人」模式的处理流程。取消选择前已提交的文本翻译任务可能继续完成。

「隐藏的原文语言」默认不隐藏任何语言。桌面端可通过可搜索的语言选择器添加语言，点击已选语言的移除按钮可取消隐藏；VR 中可在语言页选择要隐藏的语言。隐藏名单独立保存，不随翻译目标语言变化。清空选择则不按语言隐藏。例如选择中文后，对方的中文原文及其译文会一起隐藏；日文原文和对应的中文译文仍然显示。

语言过滤优先采用服务返回的原文语言；缺少标记时，根据原文在本地判断。低置信度或混合语言无法确定时继续显示。隐藏设置只影响显示，不删除历史、不停止音频处理，也不影响自己的麦克风字幕。隐藏的内容不占玩家显示名额。

## 多人字幕与状态提示

桌面字幕、VR 视野字幕和手腕对话按讲话人纵向排列，各自更新实时原文与译文。每条音轨使用独立身份，识别服务返回的讲话人划分不会替换玩家归属；同名玩家也不会因此合并。

「同时显示的玩家数」默认 **4 人**，可设置为 1–64 人或不限制。正在讲话的玩家优先显示，空余位置保留其他玩家的已完成字幕。桌面小窗会按显示人数增高，最高 720 像素，内容超出时可滚动查看。

「同时处理的玩家数」默认**不限制**，也可设置为 1–8 人。它控制实际音频处理；显示人数仅控制界面内容，降低显示人数不会减少后台识别、翻译请求或服务费用。

等待游戏、等待世界、获取密钥和失败原因会同步到已开启的 VR 字幕与手腕对话。密钥认证或缓存复用成功会短暂提示约 5 秒，等待和失败状态持续到状态改变。这些提示不进入对话历史或翻译服务。

## 会话与并发

当前登录会话的密钥保存在内存中，切换世界、停止后重新开始采集时会先尝试复用。重新登录后，通过新流量认证发现旧密钥失效，再自动获取。退出 VRCS 会清除缓存。

每位玩家拥有独立的音频缓冲、断句、识别会话和字幕编号。原生流式同传持续发送该玩家的音频并展示增量结果；某条音轨拥塞或中断时，程序单独处理该音轨。总体处理能力仍受设备资源、网络和服务额度限制。

对于 Qwen AI / 百炼 LiveTranslate，程序对同平台、地域和模型的新建连接与重连共用调度队列。首个连接立即尝试，后续启动至少间隔 6.1 秒，已连接的音轨继续并行传输。收到请求限流后，重试等待依次为 **5、10、15 秒**，后续最多 15 秒。

排队期间保留最近约 3 秒音频，较长等待可能丢失更早的话语。Qwen 同传会话可以保留至最后一块 PCM 后 90 秒，以便玩家再次讲话时复用；离开世界、取消选择或停止采集会关闭相关会话。服务账户的实际额度和其他程序的用量仍会影响连接成功率。

## 数据处理与限制

使用云端服务时，各音轨会分别发送给所选识别或同传服务，文字翻译使用所选翻译服务。多人并发可能增加费用。VRCS 不将原始音频、分页文件内容或会话密钥写入磁盘；字幕历史保存文字、译文和玩家身份信息，所选玩家的用户 ID 与昵称随配置保存。

原始音轨不应用游戏内的距离衰减、音量和静音过滤，VRCS 的音量门限仍逐轨生效。请告知参与者并取得其同意；禁止用于未经同意的监听、骚扰或侵权。

本功能不直接读取游戏进程内存，也不修改游戏文件。任何第三方工具的使用都存在被反作弊系统（EAC）判定为异常的风险，本项目不保证账号安全。功能仍处于实验阶段，可能出现漏包、延迟、姓名缺失或识别错误；使用前请阅读应用内完整说明。

## 常见问题

| 现象 | 说明与处理 |
| --- | --- |
| 一直等待世界加载 | 确认已进入世界，并且当前 VRChat 的标准日志开启、可读。 |
| 只显示「音轨 N」 | 保持采集并重新加载世界，以接收玩家身份信息；姓名到达后会自动补全。 |
| 密钥认证成功，但没有字幕 | 认证成功表示可以接收语音。检查是否有人讲话、玩家是否被选中，以及识别服务配置和界面隐藏设置。 |
| 获取密钥失败 | 检查管理员权限、内存压缩及重启状态、分页文件盘符和 NTFS 文件系统；结合界面错误详情排查。 |
| 多人开始讲话后部分字幕较晚出现 | 独立音轨需要分别建立服务会话。连接排队、服务限流和网络延迟都可能影响首次结果。 |

## 工作原理与开发入口

Rust 采集模块通过 `GetExtendedUdpTable` 识别 VRChat 的 UDP 端口，再使用 `SIO_RCVALL/RCVALL_IPLEVEL` 被动接收数据。密钥获取通过 Windows 分页相关接口与 NTFS 分页文件读取完成，候选密钥必须通过近期数据包的 AES-256-GCM 认证。

Photon / USpeak 消息按连接、世界、玩家及加入代次分流。各音轨独立进行去重、乱序缓冲和 Opus 解码，输出 16 kHz、单声道 f32 PCM，以 512 样本块接入公共语音管线。扫描、消息重组和音频队列均设有容量或时间限制。

| 模块 | 职责 |
| --- | --- |
| [`core/src/player_audio`](../core/src/player_audio) | Windows 被动采集、分页文件读取、会话缓存、玩家身份解析与音频解码 |
| [`crates/player-audio-scan`](../crates/player-audio-scan) | 候选密钥搜索、过滤与认证 |
| [`core/src/pipeline/players.rs`](../core/src/pipeline/players.rs) | 逐玩家识别任务、音频队列与服务会话管理 |
| [`apps/desktop/src/subtitles/player-history.ts`](../apps/desktop/src/subtitles/player-history.ts) | 原文语言判断与共享显示过滤 |
| [`apps/desktop/src/vr-surface/caption-visibility.ts`](../apps/desktop/src/vr-surface/caption-visibility.ts) | VR 字幕与手腕对话的显示筛选 |
